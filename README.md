Python Fundamentals — Beginner to Intermediate

A structured and beginner-friendly collection of **Python fundamentals, concepts, built-in functions, programming techniques, and practical examples**, developed using Jupyter Notebooks. This repository is designed to build a strong foundation in Python with an emphasis on **conceptual understanding, hands-on practice, readability, and real-world applicability**.

Rather than focusing only on syntax, the notebooks explain **how and why Python features work**, supported by simple examples, practical scenarios, and progressively structured exercises. The goal is to develop the programming foundation required for **Data Analytics, Data Science, Machine Learning, and automation workflows**.

## 📌 Key Topics Covered

* **Python Basics**

  * Variables, data types, operators, expressions, and type conversion
  * Strings, formatting, Unicode, ASCII, encoding and decoding
  * Numbers, Boolean values, complex numbers, and mathematical operations

* **Python Data Structures**

  * Lists, tuples, sets, and dictionaries
  * Indexing, slicing, iteration, and common operations
  * Practical manipulation and transformation of collections

* **Control Flow & Iteration**

  * `if`, `elif`, `else`
  * `for` and `while` loops
  * `break`, `continue`, and `pass`
  * Nested loops and practical iteration patterns

* **Functions & Functional Programming**

  * Defining and calling functions
  * Parameters, arguments, return values, and scope
  * Lambda functions
  * `map()`, `filter()`, `all()`, `any()`, `enumerate()`, and `zip()`

* **Python Built-in Functions**

  * Practical exploration of Python's built-in functions
  * Conversion and formatting functions such as `int()`, `float()`, `str()`, `bin()`, `oct()`, `hex()`, and `format()`
  * Character and representation functions such as `chr()`, `ord()`, `ascii()`, and `repr()`
  * Object and attribute-related functions such as `getattr()`
  * Debugging and interactive tools such as `print()`, `help()`, and `breakpoint()`

* **File Handling & Data Processing**

  * Reading from and writing to files
  * Working with CSV and JSON data
  * Exception handling using `try`, `except`, and related constructs
  * Basic data validation and type conversion

* **Object-Oriented & Advanced Python Concepts**

  * Classes, objects, methods, and attributes
  * `classmethod`, `staticmethod`, and `property`
  * Object introspection and Python's built-in capabilities
  * Compilation and execution concepts using `compile()`, `eval()`, and `exec()`

## 🎯 Learning Approach

Each topic follows a **concept → example → explanation → practical application** approach. The examples are intentionally kept simple and understandable while gradually introducing more advanced Python concepts.

This repository reflects my approach to learning programming by focusing not only on **writing code**, but also on understanding **logic, problem-solving, debugging, data manipulation, and Python's underlying behavior**.
